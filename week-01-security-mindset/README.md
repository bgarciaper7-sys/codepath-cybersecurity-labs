# Week 1: The Security Mindset

## Overview
In this unit of CodePath CYB101, I studied how cybersecurity professionals identify and evaluate risks, threats, vulnerabilities, and assets.

## Topics Covered
- Assets, threats, vulnerabilities, and risks
- Threat modeling and security controls
- Cybersecurity culture and defensive thinking
- Introduction to Capture the Flag (CTF) challenges

## Tools and Activities
- CodePath learning materials
- Introductory cybersecurity exercises and CTF activities

## Key Takeaways
- A threat is a potential cause of harm, while a vulnerability is a weakness that can be exploited.
- Risk involves the likelihood and impact of a threat exploiting a vulnerability.
- Security controls help reduce risk.
