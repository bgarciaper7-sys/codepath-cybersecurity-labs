# Week 2: Encryption and Secure Communication

## Overview
In CodePath CYB101 Unit 2, I studied how encryption
protects information and how security professionals
use command-line tools.

## Topics Covered
- Encryption and decryption
- Symmetric vs. asymmetric encryption
- Encoding vs. encryption vs. hashing
- Secure communication
- Terminal fundamentals and SSH

## Tools Explored
- CyberChef
- Command-line terminal
- SSH

## Key Takeaways
- Symmetric encryption uses a shared secret key.
- Asymmetric encryption uses public and private keys.
- Encoding is not a security mechanism.
- Hashing is a one-way operation.
- SSH enables encrypted remote communication.
